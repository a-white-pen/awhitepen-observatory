The look, in one file

Everything a build needs to look and read like awhitepen: the two-palette token set, the type system, the components, and the rules that hold them together. Self-contained — drop it into any repo and open it. The values shown are the live build's values.

How to reuse this

Copy the :root / [data-theme="dark"] block and the font <link> from the top of this file's source. Read §Colour–§Space for what each token is for, lift the component CSS at the bottom of the <style> block as-is, and keep the four laws. Which hue means which data category is a per-site choice — it is not baked into the palette.

  • A value that has a token is never written as a literal.
  • Every colour is declared in both themes.
  • A style that is the same on every render is a class, not an inline style.
  • Large fill → dusty --d-*; small mark → vivid --c-*.

02 · Type

Three families, one job each

Schibsted Grotesk (--display) for headlines, titles and hero figures · Figtree (--body) for prose, labels, UI and numbers in rows · IBM Plex Mono (--mono) for dates, category meta and code. Mixing the jobs is the fastest way to stop looking like this site.

05 · Identity

The notebook motif

A faint graph-paper texture (--grid, 26px) sits in the lower-right of every page — you can see it behind this one — and the same idea, tighter at 22px (--qgrid), lines the quote box. With the pen mark it is the notebook the site is named for. Optional on a sister site, but it is the thing people recognise.

06 · Rules that keep it coherent

Conventions & breakpoints

BEM — block__element--modifier, one block per component. Tokens, not literals — three exceptions only: media-query conditions (custom properties are not allowed there), editor swatch hexes (attribute selectors must match literal text), and deliberately theme-flat colours (which point at a flat token). No static inline styles — inline is only for values that come from data, like a bar width or a series colour. Responsive: components adapt, they do not shrink — a table becomes rows, a row becomes a stack; nothing scales down until it is unreadable.

max-widthWhat changes
1024header search hides
860header collapses to the menu button; footer embed grid stacks
640the phone break — search, rows, post chrome
600dashboard tabs wrap; TODAY's sheet goes single column
520year and panel grids stack
480split readouts stack

Reuse these six. Four one-offs (900/820/760/440) and two off-by-one partners (859/599) exist in the build for single components — add a seventh only when a component genuinely breaks somewhere else.
